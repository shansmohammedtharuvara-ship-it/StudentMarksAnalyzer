# `StudentmarksAnalyzer.cpp`

A beginner C++ project that reads student marks and calculates their total, average, highest mark, lowest mark, and pass/fail counts.

## Features

- Accepts a student count from 1 to 100
- Reads marks from 0 to 100
- Counts marks of 40 or higher as passing
- Lets the user run the analysis again

## How to Compile and Run

```powershell
g++ StudentmarksAnalyzer.cpp -o StudentmarksAnalyzer.exe
.\StudentmarksAnalyzer.exe
```

## Concepts Used

Functions, arrays, loops, and dynamic memory using `new[]` and `delete[]`.
